# منشئ الصفحات العربي (Arabic Page Builder)

الحالة: المراحل 1–8: منطق `core` (النموذج، التعديل والتراجع، المولّد، مصدّر ZIP، الحفظ المحلي، أرشيف المشروع، جلسة المحرر) + واجهة التطبيق (الشاشة الرئيسية، المحرر بقائمة البنية ولوحات الإضافة والخصائص والنقل، المعاينة الحية، عرض الكود).
لا يوجد بعد: السحب والإفلات (المرحلة 9)، بقية أنواع العناصر (10)، تصدير ZIP من الواجهة (11). لم يُبنَ المشروع بعد؛ أول تحقق فعلي هو GitHub Actions.

## التشغيل
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (الفرع `main`).
2. سير **Build Debug APK** يعمل تلقائيًا. إن لم يكن Gradle Wrapper في المستودع يولّده بنفسه لهذا التشغيل، ويرفع ملفاته كـ Artifact باسم `gradle-wrapper-files` لتضيفها إلى المستودع (اختياري لكنه مستحسن).
3. نزّل `app-debug-apk` من نتائج التشغيل.

## تحديث التطبيق فوق النسخة المثبّتة (بدون حذف)
- `applicationId` ثابت (`com.arabicpagebuilder`).
- `versionCode` يزيد مع كل بناء (دقائق منذ 1970).
- التوقيع ثابت: مفتاح debug داخل المستودع (`app/debug.keystore`) وليس مفتاحًا عشوائيًا من GitHub. تأكد من رفعه مع بقية الملفات (`.gitignore` يستثنيه).
- في كل تشغيل يطبع السير بصمة SHA-256 للتوقيع في ملخص التشغيل؛ إن بقيت ثابتة فالتحديث فوق النسخة سيعمل.
- **ملاحظة:** أي نسخة ثُبّتت سابقًا بتوقيع مختلف (قبل هذا الإصدار) تحتاج حذفًا مرة واحدة فقط، وبعدها تُحدَّث تلقائيًا.
- المفتاح للاختبار الشخصي فقط (غير سري). للنشر الرسمي نستخدم مفتاحًا سريًا في GitHub Secrets في مرحلة مستقلة، وسيتطلب إعادة تثبيت واحدة عند الانتقال إليه.
